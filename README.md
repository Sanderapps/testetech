# MeGamerz

Portal editorial responsivo de notícias, reviews, cultura gamer e lançamentos.

## Direção visual

Layout original construído para o projeto, com referências de linguagem editorial e interação pesquisadas em galerias de design e no Codrops. Não há template de terceiros copiado no código.

Referências de pesquisa:
- Codrops — Animated Product Grid Preview with GSAP & Clip-Path: https://tympanus.net/codrops/2025/05/27/animated-product-grid-preview-with-gsap-clip-path/
- Codrops Creative Hub: https://tympanus.net/codrops/hub/
- Behance — IMGAMER Gaming News Website Design: https://www.behance.net/gallery/170187309/IMGAMER-Gaming-news-website-design
- Behance — Game news landing page: https://www.behance.net/gallery/151116459/web-site-design-Game-news-landing-page

## Interações implementadas

- hero com parallax/tilt 3D por ponteiro;
- cards com beam animado e zoom editorial;
- ticker contínuo;
- reveal por IntersectionObserver;
- barra de progresso da página;
- menu mobile com clip-path;
- busca em overlay e filtro em tempo real;
- filtros por plataforma;
- botões magnéticos;
- órbitas CSS animadas no especial de eSports;
- scores em conic-gradient;
- suporte a `prefers-reduced-motion`.
